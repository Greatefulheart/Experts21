# SOP authoring

## Template
```
SOP: <name>           Owner: <role>        Version/date:
Purpose: one sentence
When: trigger or time
Who: role(s)
Tools/supplies:
Steps: numbered, one action per step, with the standard (time, temperature, quantity)
Checks: how we know it was done right
If something goes wrong: what to do, who to call
```

## Core SOP set
Opening; closing; espresso dial-in; milk and cold-chain; cleaning (daily/weekly/monthly); cash and card reconciliation; receiving deliveries; mobile-order handling; service recovery; equipment failure (switch to batch brew); power outage; hurricane watch/warning/after-storm reopening.

## Rules
- Bilingual where staff need it; short sentences; photos or diagrams for stations.
- Each SOP has an owner and a review date; test it with a new staff member.
