# KPI dashboard and alerts

## Core KPIs
| KPI | Definition | Target / alert |
|---|---|---|
| Transactions per day | POS tickets | Plan; alert if below plan 4 weeks running |
| Average ticket | Net sales / tickets | ~$7.50 base (Estimate) |
| Attach rate | Tickets with food or add-on / tickets | Track trend |
| Labor % | Labor cost incl. taxes / net sales | 28–35%; alert above 35% for a month |
| COGS % | Cost of goods / net sales | 25–35%; alert above 32% for a month |
| Occupancy % | Rent + NNN / net sales | at or below 10–12%; alert above 15% |
| Cash runway | Cash / average monthly burn | alert below 3 months |
| Google rating | Average and count | alert below 4.5 |
| App/online share | App orders / tickets | Track trend |
| Loyalty repeat rate | Repeat members / members | Track trend |

## Early-warning indicators (docs/08)
Weekly transactions below plan 4 weeks in a row; labor above 35% or COGS above 32% for a month; runway under 3 months; rating below 4.5; an active tropical system with Miami in the forecast cone.

## Rules
Daily for sales, weekly for labor and inventory, monthly for P&L. Every alert names an owner and a next action.
